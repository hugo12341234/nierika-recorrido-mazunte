## j.5 Team member D2 (321332086)

**Participation.** In this project I acted as coordinator and integrator. I set up the repository and the build: the solution we inherited from a class practice was a 32-bit project, so I converted it to x64 and used vcpkg in manifest mode so that the libraries (GLFW, GLEW, GLM and Assimp) had fixed versions. I recorded the scope and acceptance decisions in the project status file. I built the beach and the sea, generated most of the 3D models and textures with Python scripts for Blender, and integrated my teammate’s lighting and Maya models into the scene. In the last week I extended the project with a guided tour with narration, a start menu, more cultural cards and five new animations. Almost all the commits in the repository carry my name (491 of the 493 commits on the `develop` branch). I want to be honest that I used an AI assistant (Claude) to produce code, scripts and documents at my request; I decided what to build, tested it in Visual Studio 2022 and approved each change before merging it.

**Difficulties.** The first difficulty was technical: the inherited code was in 32 bits and used scales that did not match one unit per meter, so I had to fix the base before adding anything new. The biggest difficulty, however, was organizational. For several weeks there was very little activity, and my teammate’s work reached the repository late and outside Git, so I had to integrate and correct it myself. As a result, the schedule was compressed into the last two weeks. Another problem was performance: on a laptop with integrated graphics the program ran at about 15 FPS. We measured it, found thousands of draw calls and too many lights per pixel, and applied frustum culling and other optimizations until it reached at least 45 FPS.

**Learning.** I learned how a real-time render loop works in OpenGL and how shaders control the final image: Blinn-Phong lighting with several types of lights, Perlin noise for the candle flames, and sine waves in the vertex shader for the sea. I also learned keyframe animation with interpolation and quaternions. Outside graphics, I learned to use Git with branches and pull requests, to organize tasks on a Kanban board, and to write down decisions so that the project can be audited. Working with an AI assistant taught me that it is fast, but only useful if I check every result; I learned to ask for verification and to reject changes that I did not understand.

**Looking back.** I would start much earlier and spread the work over the eight weeks instead of the last two. I would measure performance from the first scene, not on the last day. I would also insist from the beginning that both members commit their own work to the repository and review each other’s changes, and I would keep a log of real hours to compare against the plan.
