## Qué falta para cerrar E-6

1. Capturas reales de cada sección (ver `capturas/README.md`).
2. Rellenar las secciones PENDIENTES cuando existan colisiones (A-9), animaciones (C-x, D-x), fichas (C-7) y audio (D-6).
3. Revisar los controles contra `main.cpp` una vez más al cerrar E-2 (los de depuración deben haber salido).
4. Versión en inglés.
5. Exportar a PDF y revisar formato (sin logos de la escuela ni datos personales; solo números de cuenta).
